UrbanTracker. La plataforma permite ver buses en tiempo real y administrar rutas sin depender de hardware costoso. Por detrás corre un backend en Spring Boot con PostgreSQL; por delante, una web (React/Next.js) para usuarios y administración, y una app de conductor en React Native. Usamos WebSockets y, cuando conviene, MQTT con un broker tipo Mosquitto. Con esta base obtuvimos envíos de posición cada ~5 segundos y una latencia menor a 2 segundos desde el móvil del conductor hasta la pantalla del usuario en condiciones 4G normales. La API REST está documentada (OpenAPI), el acceso se protege con JWT y el panel permite gestionar rutas, vehículos y conductores. El enfoque de usar el celular del conductor bajó costos y aceleró el arranque ("CITY-RUTA", 2018; "STOPBUS", 2016; "SisMo", 2016; EasyRest, 2022; "Aspectos de ingeniería...", 2022).
